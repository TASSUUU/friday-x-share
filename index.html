Connect without internet

  1. Turn on a mobile hotspot on one device, or use an existing Wi‑Fi router.
  2. Connect the second device to that same network.
  3. Open this HTML page in a modern browser on both devices.
  4. Use Send on one device and Receive on the other.
  5. Exchange the 6-digit codes to pair.
🛡️

Compatibility & privacy

  • WebRTC data channels encrypt the connection.
  • No cloud upload or account is used by this page.
  • Some browsers block local peer connections from file:// pages. If pairing fails, host this page on a local network server or use a trusted HTTPS origin.
